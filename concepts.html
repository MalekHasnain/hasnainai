Core Concepts

Each concept below is defined once, in learning order — every definition builds on the one before it, and the topic pages link back here instead of repeating. Read top to bottom the first time; afterwards use it as your dictionary.

Neeche har concept ek hi baar define hua hai, seekhne ki tarteeb mein — har taaruf pichle par khara hota hai, aur topic pages yahan wapas link karte hain baja ye dohrane ke. Pehli dafa upar se neeche parho; uske baad ise dictionary ki tarah use karo.

1. The data you learn from

Everything starts with a table of examples. Before any algorithm, you must be able to name the parts of that table.

Har cheez ka aaghaz misalon ki table se hota hai. Kisi algorithm se pehle aapko is table ke hisson ke naam aane chahiye.

Sample: one row of the dataset — one house, one patient, one image. 1,000 rows = 1,000 samples the model can learn from.dataset ki ek row — ek ghar, ek mareez, ek tasveer. 1,000 rows = 1,000 misalein jin se model seekh sakta hai.
Feature (X, independent variable): an input column used to make a prediction — house size, age, pixel values. The cause side of the problem.woh input column jis se prediction hoti hai — ghar ka size, umar, pixel values. Masle ka sabab wala rukh.
Target variable (y, dependent variable): the output column the model is trained to predict — the effect. Continuous target (price, temperature) → regression problem. Category target (spam/ham, cat/dog) → classification problem.woh output column jo model predict karna seekhta hai — yaani asar. Continuous target (price, temperature) → regression problem. Category target (spam/ham) → classification problem.
ExampleColumn type
Xsize, bedrooms, agenumbers or categories
ypricewhat you predict
Probability sample: chosen by random chance where every member has a known chance of being picked (simple random, stratified, systematic, cluster). Results generalize to the population.random chance se chuna gaya namoona jahan har member ke chune jane ki probability maloom ho. Nateeja poori population par laagu hota hai.
Non-probability sample: chosen by convenience or judgment (convenience, snowball, quota). Cheaper, but biased — findings may not generalize.aasani ya raye se chuna gaya (convenience, snowball, quota). Sasta magar biased — nateeja population par laagu na ho.
Imputer / missing data: real datasets have empty cells. An imputer fills them mechanically — e.g. SimpleImputer(strategy='mean') replaces each hole with that column's mean.asli datasets mein khali cells hoti hain. Imputer unhe mechanical tor par bhar deta hai — masalan mean strategy har khali jagah us column ka average laga deti hai.

2. How a model is graded honestly

The one mistake that ruins every ML project: grading a student on a question it has already seen.

Woh ek ghalti jo har ML project barbaad kar deti hai: student ko us sawal par imtihana dena jo usne pehle hi dekh rakha ho.

Train/test split: hide part of the data (commonly 20%) before training. The model learns from the 80% and is graded on the unseen 20%. random_state freezes the shuffle so results are reproducible.training se pehle data ka hissa (aam tor par 20%) chhupa do. Model 80% se seekhta hai aur an-dekhe 20% par imtihana hota hai. random_state shuffle ko fix rakhta hai taake nateeja dohraya ja sake.
Overfitting: the model memorizes the training data — including its noise — and fails on new data. Symptom: train score high, test score low. Fixes: more data, fewer features, regularization, cross-validation.model training data ko — us ke shor samet — rat leta hai aur naye par fail hota hai. Alamat: train score uncha, test score neecha. Ilaaj: zyada data, kam features, regularization, cross-validation.
Underfitting: the model is too simple to capture the real pattern. Symptom: both train and test scores low. Fixes: add features, use a more powerful model, train longer.model itna simple hai ke asli pattern pakar hi nahi sakta. Alamat: train aur test dono neeche. Ilaaj: features barhao, taqatwar model lo, zyada train karo.
ConditionTrainTestDiagnosis
Overfittinghighlowmemorized — simplify or add data
Underfittinglowlowtoo simple — add power
Good fithighhigh (small gap)ship it

Now that overfitting and underfitting have faces, we can define the two causes behind them:

Jab overfitting aur underfitting ke chehre maloom ho gaye, to ab unke peeche ki dono wajuhaat define kar sakte hain:

Bias: error from the model's wrong assumptions — too rigid to bend to the real pattern. A straight line on curved data has high bias no matter how much data you give it. High bias → underfitting. Think: "too simple to see the truth."model ki ghalat assumptions se paida hone wali ghalti — asli pattern par jhukne se qasar. Mudeer data par seedhi line ka bias uncha rahega, chahe jitna hi data do. Bara bias → underfitting. Yaad rakho: "asal haqeeqat dekhne se simple hai."
Variance: error from being too sensitive to the particular samples trained on — retrain on a different 80% and you get a wildly different model. High variance → overfitting. Think: "chases noise instead of signal."un khaas misalon ke prati zyada hassas hona jin par train hua — doosre 80% par dobara train karo to bilkul alag model ban jata hai. Bara variance → overfitting. Yaad rakho: "signal ki jagah shor ka peechha."
Bias-variance tradeoff: you cannot fully minimize both — decreasing one usually increases the other. The goal is the sweet spot: flexible enough to capture the pattern, rigid enough to ignore the noise.dono ko poora kam nahi kar sakte — ek kam karo to doosra barhta hai. Maqsad darmiyani jagah hai: pattern pakarne ke qabil itna lachakdar, shor ignore karne ke qabil itna sakht.
Cross-validation: rotating the test set — split into K folds, train on K−1, test on 1, rotate, average. One number, far harder to fool.test set ko ghumana — K folds mein toro, K−1 par train karo, 1 par test karo, ghumaao, average lo. Ek number jise dhokha dena mushkil hai.

3. Data problems you must handle

Anomaly / outlier detection: IQR rule — below Q1 − 1.5·IQR or above Q3 + 1.5·IQR; Z-score — |z| > 3; DBSCAN noise points (Topic 03); Isolation Forest. A boxplot shows them visually.IQR rule — Q1 − 1.5·IQR se neeche ya Q3 + 1.5·IQR se upar; Z-score — |z| > 3; DBSCAN ke noise points (Topic 03); Isolation Forest. Boxplot se aankhon se dikh jate hain.
Data augmentation: creating synthetic examples — jittering (small noise on features), SMOTE (synthetic point between a sample and a neighbor), bootstrapping (sampling with replacement); images: flip/rotate/crop. Overdone augmentation adds bias.masnoori misalein banana — jittering (features par chhota shor), SMOTE (misal aur uske hamsaye ke darmiyan naya point), bootstrapping (wapas rakh kar namoona); tasveeron ke liye: palto/ghumao/kaato. Had se zyada augmentation bias daalta hai.

4. Math & stat functions (the toolbox every algorithm uses)

Every algorithm in this course is built from the same dozen math parts. Learn them once here, recognize them everywhere.

Is course ka har algorithm unhi bara-bara math hisson se banta hai. Yahan ek dafa seekh lo — har jagah pehchan lo ge.

Mean (μ, x̄): sum of all values ÷ number of values — the average, the balance point of the data.values ka sum ÷ number of values — yani average; data ka balance point.

Worked example — marks of 5 students in a test:

Misal — 5 students ke test marks:

StudentABCDESum
Marks (out of 100)6275758895395

Mean = 395 ÷ 5 = 79 — add the values, divide by the count; that is the whole formula.Mean = 395 ÷ 5 = 79 — values ko add karo, unki count se divide karo, formula bas itna hi hai.

Median: the middle value after sorting — half the data sits below it, half above. Robust: one crazy value barely moves it (mean jumps).sort karne ke baad ka middle value — aadha data isse neeche, aadha upar. Robust: ek outlier isse zyada hila nahi pata (mean jump kar jata hai).

Same marks, sorted: 62, 75, 75, 88, 95 → median = 75 (3rd of 5). Add one rich kid scoring 100 → mean jumps to 82.5, median moves only to 81.5.

Wohi marks, sorted: 62, 75, 75, 88, 95 → median = 75 (5 mein se 3rd). Ek 100-score student add karo → mean 82.5 tak jump karta hai, median sirf 81.5 tak.

Variance (σ²): average of squared distances from the mean — how spread out the data is. Steps: (1) subtract mean from every value, (2) square each answer, (3) average the squares.mean se distance ke squares ka average — batata hai data kitna spread out hai. Steps: (1) har value mein se mean minus karo, (2) har answer square karo, (3) squares ka average lo.

Worked example — same marks, mean = 79:

Misal — wohi marks, mean = 79:

Marks (x)6275758895Sum
x − mean−17−4−4+9+160 ✓
(x − mean)²289161681256658

Variance = 658 ÷ 5 = 131.6. Note: deviations always sum to 0 — that's the mean being the balance point.Variance = 658 ÷ 5 = 131.6. Note: deviations ka sum hamesha 0 hota hai — yehi mean ka balance point hona hai.

Standard deviation (σ, std): square root of variance — spread in the data's own units, so "σ = 5 years" means something.variance ka square root — spread apni original units mein, is liye "σ = 5 saal" ka matlab samajh aata hai.

σ = √131.6 ≈ 11.5 marks — typical distance of a student from the class average.σ = √131.6 ≈ 11.5 marks — kisi student ka class average se typical distance.

Z-score: how many standard deviations a value is from the mean: z = (x − mean) ÷ σ. This is the anomaly detector — |z| > 3 means "extremely unusual".koi value mean se kitne standard deviations door hai: z = (x − mean) ÷ σ. Yehi anomaly detector hai — |z| > 3 ka matlab "bahut hi unusual".

Student E scored 95 → z = (95 − 79) ÷ 11.5 ≈ +1.39 (good but normal). A new student scores 30 → z = (30 − 79) ÷ 11.5 ≈ −4.3 → |z| > 3 → anomaly, investigate.Student E ne 95 score kiya → z = (95 − 79) ÷ 11.5 ≈ +1.39 (achha magar normal). Naya student 30 score kare → z = (30 − 79) ÷ 11.5 ≈ −4.3 → |z| > 3 → anomaly, investigate karo.

Covariance: how two variables move together — positive = together, negative = opposite. Awkward units, which is why correlation exists.do variables sath kaise chalti hain — positive = sath, negative = ulat. Units ajeeb hote hain (e.g. hours×marks), isi liye correlation banayi gayi.

Worked example — study hours (x) vs test marks (y), 5 students. Means: x̄ = 3, ȳ = 69:

Misal — study hours (x) aur test marks (y), 5 students. Means: x̄ = 3, ȳ = 69:

Covariance = 100 ÷ 5 = 20 — positive, so the two move together (more hours → more marks). But "20 hours×marks" is a meaningless unit — that is exactly why correlation exists:Covariance = 100 ÷ 5 = 20 — positive, yani dono sath chalti hain (zyada hours → zyada marks). Magar "20 hours×marks" unit ka koi matlab nahi — yehi wajah hai ke correlation banayi gayi:

Pearson correlation (r): covariance ÷ (std(X)·std(y)) — scaled to −1…+1. |r| near 1 = strong straight-line relationship.covariance ÷ (std(X)·std(y)) — −1 se +1 tak scale. |r| 1 ke qareeb = mazboot seedha rishta.

Continuing: σx = 1.414, σy = 14.283 → r = 20 ÷ (1.414 × 14.283) = 0.99 — a near-perfect positive straight-line relationship, now as a unit-free number you can compare across any datasets.Aage: σx = 1.414, σy = 14.283 → r = 20 ÷ (1.414 × 14.283) = 0.99 — taqreeban perfect positive straight-line rishta, ab unit-free number jo kisi bhi datasets ke darmiyan compare ho sakta hai.

Percentile / quartile: Q1 = 25th percentile, Q3 = 75th. IQR = Q3 − Q1 — the middle 50% width, the box in a boxplot.Q1 = 25th percentile, Q3 = 75th. IQR = Q3 − Q1 — darmiyani 50% ki chaurai, boxplot ka dabba.

Outlier fences: Q1 − 1.5×IQR = 34, Q3 + 1.5×IQR = 126 — anything below 34 or above 126 is an outlier. Our class: all inside, no outliers.Outlier fences: Q1 − 1.5×IQR = 34, Q3 + 1.5×IQR = 126 — 34 se neeche ya 126 se upar koi bhi value outlier hai. Hamari class: sab andar, koi outlier nahi.

Distance metrics: Euclidean = straight-line distance (√ of summed squared differences) — what K-Means uses; Manhattan = city-block distance.Euclidean = seedhi line doori — K-Means yehi use karta hai; Manhattan = shehar ke blocks wali doori.

Worked example — student A at point (1, 2), student B at point (4, 6):

Euclidean = "as the crow flies"; Manhattan = a taxi driving block by block. K-Means uses Euclidean to pick the nearest centroid.Euclidean = "kauwa udta hua jo seedha jaye"; Manhattan = taxi block-by-block chalta hua. K-Means nearest centroid chunne ke liye Euclidean use karta hai.

Matrix / eigenvector / eigenvalue / determinant: a matrix transforms vectors; an eigenvector is a direction it only stretches (not rotates), the eigenvalue (λ) is the stretch factor; the determinant is the volume-scaling factor. PCA finds the eigenvectors of the covariance matrix — biggest λ = direction of most spread.matrix vectors ko transform karti hai; eigenvector woh simt hai jise sirf khicha jata hai (ghumaya nahi), eigenvalue (λ) khichao ka factor hai; determinant volume ka factor hai. PCA covariance matrix ke eigenvectors nikalti hai — sab se bara λ = sab se zyada spread ki simt.

Worked example — matrix M = [[2,0],[0,3]] stretches x by 2 and y by 3:

Misal — matrix M = [[2,0],[0,3]] x ko 2 se aur y ko 3 se stretch karti hai:

VectorM × vectorResult

(0, 1)(0, 3)same direction, stretched ×3 → eigenvector, λ = 3
(1, 1)(2, 3)direction bent — not an eigenvector

In PCA the covariance matrix plays the role of M: its biggest-λ eigenvector = the direction where data spreads most = the first principal component.PCA mein covariance matrix M ka role play karti hai: iska sab se bara-λ eigenvector = woh direction jahan data sab se zyada spread hai = first principal component.

Derivative & gradient descent: the derivative is the slope; gradient descent loops: measure the error's slope, step downhill, repeat — the training engine of neural networks.derivative yani slope hai; gradient descent ka loop: error ka slope naapo, neeche qadam barhao, dohrate jao — neural networks ka training engine.

Worked example — minimize f(x) = (x−4)². Derivative (slope) = 2(x−4). Learning rate 0.3, start at x = 0:

Misal — f(x) = (x−4)² ko minimize karo. Derivative (slope) = 2(x−4). Learning rate 0.3, start x = 0:

Step012345
x0.02.403.363.743.903.96

Each step: new x = x − 0.3 × slope. Steps shrink as the slope flattens; x converges to 4 — the minimum. Neural networks run this exact loop with millions of numbers at once.Har step: new x = x − 0.3 × slope. Slope flat hota jata hai to steps chhote hote jate hain; x minimum (4) ki taraf converge karta hai. Neural networks yehi loop ek waqt mein millions of numbers par chalate hain.

Sigmoid (logistic) function: σ(z) = 1/(1+e−z) — squashes any number into (0, 1), S-shaped. Turns a raw score into a probability; the heart of Logistic Regression.σ(z) = 1/(1+e−z) — kisi bhi number ko (0, 1) mein daba deta hai, S shakal ka. Raw score ko probability banata hai; Logistic Regression ka dil.

Feed numbers through σ(z) = 1/(1+e−z):

Numbers ko σ(z) = 1/(1+e−z) se guzaro:

z−4−20+2+4
σ(z)0.020.120.500.880.98

Output is always between 0 and 1 → read it as a probability. σ(0) = 0.5 is the decision boundary; z = +2 already means "88% sure yes".Output hamesha 0 aur 1 ke darmiyan → ise probability ki tarah parho. σ(0) = 0.5 decision boundary hai; z = +2 ka matlab "88% sure yes".

Softmax: sigmoid's multi-class sibling — converts a vector of scores into probabilities summing to 1. CNN output layer.sigmoid ka multi-class bhai — scores ke vector ko aisi probabilities mein badalta hai jin ka sum 1 ho. CNN ka output layer.

Log loss / cross-entropy: the classification loss — brutally punishes confident wrong predictions.classification ka loss — purzor ghalat predictions ko sakht saza deta hai.

Argmax: the index of the largest value — "which class has the top probability."sab se bare value ka index — "kis class ki probability sab se zyada hai."

From the softmax table: probabilities [0.87, 0.12, 0.016] → argmax = index 0 = "cat". Argmax doesn't care how big the value is — only WHICH slot holds the biggest one.Softmax table se: probabilities [0.87, 0.12, 0.016] → argmax = index 0 = "cat". Argmax ko value ke size se koi matlab nahi — sirf ye ke sab se bari value KIS slot mein hai.

Normalization / scaling: squeezing features to comparable ranges. Critical for anything measuring distance or variance: K-Means, SVM, PCA, KNN.features ko milti-julti hadon mein lana. Distance ya variance napne wale har algorithm ke liye zaroori: K-Means, SVM, PCA, KNN.

Why it matters — two features: age (0–100) and income (0–1,000,000). Raw distance is dominated by income; age becomes invisible. Min-max scale both to 0–1 and they weigh equally. Rule of thumb: any algorithm whose math contains "distance", "variance" or "gradient" needs scaling first.Yeh zaroori kyun hai — do features: age (0–100) aur income (0–1,000,000). Raw distance mein income hi sab kuch hai; age gayab ho jati hai. Min-max scaling se dono 0–1 mein aa kar barabar weight deti hain. Rule of thumb: jis algorithm ke math mein "distance", "variance" ya "gradient" ho, scaling pehle karo.
