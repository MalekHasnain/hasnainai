Core Concepts (explained ONCE — used everywhere)

These terms appear in every algorithm. Each is defined here one time only — topic pages link back to this page instead of repeating.

1. Data basics

Feature (X, independent variable): an input column used to make a prediction — e.g. house size, age, pixel values.
Target variable (y, dependent variable): the output the model is trained to predict. In supervised learning, the model learns from examples where the target is already known. Continuous target → regression; category target → classification.
Sample: one row of the dataset — one house, one patient, one image. Your notes: "imputer used to fill none value" → see Missing data below.
Probability sample: a sample chosen by random chance, where every member has a known probability of being picked (simple random, stratified, systematic, cluster). Results generalize to the population.
Non-probability sample: a sample chosen by convenience or judgment (convenience, snowball, quota). Cheaper but biased — results may not generalize.
Imputer / missing data: an imputer fills empty (None/NaN) cells, e.g. SimpleImputer(strategy='mean') replaces each missing value with that column's mean. Models crash or lie on missing data.

2. Model evaluation

Train/Test split: hiding part of the data (commonly 20%) so the model is graded on examples it never saw. If you grade on memorized data, the score is fake. random_state fixes the shuffle for reproducibility.
Overfitting: the model memorizes training data and fails on new data — train score high, test score low. Fixes: more data, fewer features, regularization (Ridge/Lasso/dropout), cross-validation.
Underfitting: the model is too simple — bad on both train and test. Fixes: more features, more complex model, train longer.
Bias: error from wrong/too-simple assumptions; high bias → underfitting. Variance: error from sensitivity to training noise; high variance → overfitting. Bias-variance tradeoff: decreasing one usually increases the other — the goal is a balance.
Cross-validation: rotating the test set — split data into K folds, train on K−1, test on 1, rotate. Gives a reliable average score and fights overfitting.

3. Data problems

Anomaly / outlier detection methods: IQR rule (outside Q1−1.5·IQR or Q3+1.5·IQR), Z-score (|z| > 3), DBSCAN noise points, Isolation Forest. Visual: boxplot.
Data augmentation (increasing a dataset artificially): jittering (small noise on features), SMOTE (synthetic points between a sample and its neighbor), bootstrapping (sampling with replacement); images: flip/rotate/crop. Overdone augmentation adds bias.

4. Math & stat functions (definitions used across all algorithms)

Mean: the average — sum of values ÷ count. The balancing point of data.
Variance (σ²): the average of squared distances from the mean — how spread out the data is.
Standard deviation (σ, std): the square root of variance — spread in the SAME units as the data.
Covariance: how two variables move together — positive = together, negative = opposite. Units are awkward (X-units × Y-units), which is why correlation exists.
Pearson correlation (r): covariance divided by (std(X)·std(y)) — scaled to −1…+1. |r| near 1 = strong linear relationship.
Percentile / quartile: Q1 = 25th percentile (25% of data below), Q3 = 75th. IQR = Q3 − Q1 = spread of the middle 50%.
Distance metrics: Euclidean = straight-line distance (√ of sum of squared differences); Manhattan = city-block distance (sum of absolute differences). K-Means uses Euclidean; DBSCAN uses either.
Matrix, eigenvector, eigenvalue: a matrix is a grid of numbers (a linear transformation). An eigenvector of a matrix is a direction the matrix does NOT rotate — it only stretches it, and the stretch factor is the eigenvalue (λ). PCA finds the eigenvectors of the covariance matrix; the biggest eigenvalues mark the directions of most variance.
Determinant: a single number computed from a square matrix — geometrically, the volume-scaling factor of the transformation. Zero determinant = matrix squashes space flat (not invertible).
Gradient descent: an optimization loop: compute the slope (gradient) of the error, step a little downhill, repeat until the error stops improving. The training engine of neural networks and logistic regression at scale.
Sigmoid (logistic) function: σ(z) = 1/(1+e−z) — squashes any number into (0, 1), S-shaped. Turns a regression score into a probability.
Softmax: the multi-class version of sigmoid — converts a vector of scores into probabilities that sum to 1.
Log loss / cross-entropy: the classification loss function — heavily punishes confident wrong predictions. What logistic regression and neural classifiers minimize.
Derivative (slope): how fast a function changes at a point. Needed for gradient descent (the gradient is made of derivatives).
Argmax: the INDEX of the largest value, not the value itself — e.g. which class has the highest probability.
Normalization / scaling: squeezing features to comparable ranges (e.g. 0–1 or mean 0 / std 1). Critical for K-Means, SVM, PCA, KNN — anything using distances.

5. Learning families

Supervised learning: learning with labels (target known). Regression + classification.
Unsupervised learning: learning without labels — finding structure. Clustering (K-Means, DBSCAN) + dimensionality reduction (PCA).
Regression: predicting a continuous number (price, temperature).
Classification: predicting a category (spam/not spam, cat/dog).
Clustering: grouping similar samples without labels.
Embedding / feature vector: representing a sample as a list of numbers (an image as 1000 numbers, a word as 300 numbers) so math can be applied.
